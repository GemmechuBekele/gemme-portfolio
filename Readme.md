# 📖 Gemmechu Bekele Portfolio <a name="about-project"></a>

**Gemmechu Bekele Portfolio** is a responsive and interactive personal portfolio website designed to introduce me as a software developer, showcase my skills and projects, and provide an easy way for visitors to learn more about me and get in touch.

The portfolio uses a **chat-style interface** that allows visitors to explore sections such as About Me, Skills, Projects, Clients, Hobbies, and Contact. It also includes dark/light mode and customizable accent colors.

## 🛠 Built With <a name="built-with"></a>

### Tech Stack <a name="tech-stack"></a>

The project was built using the following technologies:

* **HTML5** – Used to structure the portfolio.
* **CSS3** – Used for custom styling, layouts, animations, themes, and responsive design.
* **JavaScript** – Used to add interactivity and dynamic portfolio content.
* **Tailwind CSS** – Used for utility-based styling and responsive UI elements.
* **Font Awesome** – Used for icons throughout the portfolio.
* **Google Fonts (Inter)** – Used for typography.

### Key Features <a name="key-features"></a>

* **Interactive Chat-Style Portfolio** – Visitors can explore different portfolio sections through an interactive interface.
* **Dark and Light Mode** – Users can switch between dark and light themes.
* **Accent Color Selection** – Users can choose between gold, blue, green, pink, and purple accent colors.
* **Responsive Design** – The portfolio adapts to desktop, tablet, and mobile screen sizes.
* **Project Showcase** – Visitors can browse through different projects using the project navigation.
* **Skills Section** – Displays frontend, backend, database, mobile, and development tools.
* **Contact Section** – Provides contact information and links to social and developer platforms.
* **CV Download** – Visitors can download the developer's CV directly from the portfolio.

## 💻 Getting Started <a name="getting-started"></a>

To get a local copy of this project up and running, follow the steps below.

### Prerequisites

Before running the project, you need:

* A modern web browser such as Chrome, Firefox, Edge, or Safari.
* Git installed on your computer.
* A code editor such as Visual Studio Code.

### Setup

Clone this repository to your desired folder:

```bash
git clone https://github.com/GemmechuBekele/My-Portfolio-Website.git
```

Navigate into the project directory:

```bash
cd week-7
```

### Install

This project does not require any package installation because it is built with HTML, CSS, JavaScript, and Tailwind CSS through the browser CDN.

### Usage

Open the `index.html` file in your browser.

You can also use the **Live Server** extension in Visual Studio Code for a better development experience.

The portfolio allows visitors to:

* View information about Gemmechu Bekele.
* Explore technical skills.
* Browse projects.
* View professional interests.
* Access contact information.
* Download the CV.
* Switch between light and dark themes.
* Change the accent color.
* Search or type topics such as `about`, `skills`, `projects`, `clients`, or `contact`.

### Run Tests

There are currently no automated tests configured for this project.

You can manually test the main functionality by checking:

* Navigation buttons.
* Chat input.
* Project navigation.
* Dark/light mode.
* Accent color selection.
* Responsive layout.
* CV download.
* Social media links.

### Deployment

This project can be deployed using static hosting services such as:

* GitHub Pages
* Netlify
* Vercel
* Cloudflare Pages

After deployment, add the deployed URL to the **Live Demo** section above.
